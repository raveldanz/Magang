SIP-MAGANG - DEMO LEWAT WIFI (Dispusip Kota Surabaya)
=====================================================

Panduan lengkap: PANDUAN_IT_SIP-MAGANG.pdf (di folder ini).
Tidak perlu internet, Node.js, Composer, PostgreSQL, maupun instalasi apa pun.

CARA PAKAI (komputer server)
----------------------------
0. Sebelum diekstrak: klik kanan berkas zip > Properties > centang "Unblock" > OK (bila ada).
1. Klik kanan zip > Extract All > tujuan C:\  (hasilnya C:\SIP-MAGANG).
   Jangan menjalankan dari dalam zip, flashdisk, atau folder OneDrive.
2. Buka C:\SIP-MAGANG lalu klik dua kali:  1_MULAI_DEMO.bat
   - Bila muncul "Windows protected your PC": klik More info > Run anyway.
   - Bila muncul "Izinkan aplikasi ini membuat perubahan?": klik YES / YA
     (sekali saja, untuk izin Windows Firewall agar HP peserta bisa masuk).
   - Tunggu sekitar 1-2 menit sampai muncul "Server berjalan".
   - Browser otomatis membuka ALAMAT_DEMO.html (alamat + kode QR + akun demo).
     Tampilkan ke layar/proyektor; peserta cukup memindai QR.
3. JANGAN tutup jendela hitam dan jendela kecil "SIP-MAGANG ..." selama demo.

Berkas lain (tidak wajib):
  2_UJI_20_PENGGUNA.bat   uji otomatis 20 peserta selama 1 menit (saat demo menyala)
  3_RESET_DATA_DEMO.bat   kembalikan data demo ke awal (setelah demo dimatikan)
  CEK_KESIAPAN.bat        hanya memeriksa, tidak mengubah apa pun
  izinkan_firewall.bat    izin firewall manual (klik kanan > Run as administrator)

JARINGAN
--------
- Komputer server dan SEMUA perangkat peserta harus di WiFi/router yang SAMA.
- Bila komputer server pindah WiFi, alamatnya berubah: klik 1_MULAI_DEMO.bat > pilih U (ulang).
- Bila HP tidak bisa membuka alamat padahal komputer server bisa: WiFi memblokir sesama
  perangkat (client isolation). Pakai router WiFi sendiri (tidak perlu internet).

SELESAI
-------
- Hentikan: klik jendela hitam, tekan Ctrl+C, lalu Y.
- Klik 1_MULAI_DEMO.bat saat demo masih berjalan: pilih B untuk membuka lagi halaman alamat.
